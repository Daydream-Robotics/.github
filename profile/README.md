# Daydream Robotics

Daydream is the Robotics Club at Central Florida's VEX U robotics team, competing out of the University of Central Florida. Previously known as UCF7.

This organization contains the software used to control, localize, simulate, and test our competition robots.

## Main Repositories

### Robot Core

Core software for the physical robot. See **Robot Core** for the primary robot software and subsystem documentation.

### DreamSim

Our NVIDIA Isaac Sim digital-twin and simulation environment. See **DreamSim** for simulation setup and development.
